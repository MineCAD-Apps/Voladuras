# Dependencias y atribución

## Three.js y OrbitControls

Versión incluida: 0.181.0, identificada como r181. vendor/three-vendor.js se conserva con su contenido interno. vendor/THREE-LICENSE.txt contiene la licencia MIT de sus autores. No requiere CDN.

## Página externa

Panel de Voladura Subterránea, con autoría mostrada de JR Cognitive Projects: https://extraordinary-jelly-d2ae56.netlify.app/.

El repositorio contiene un iframe, un tema visual y observaciones descriptivas. No contiene una copia del código de esa página. La atribución se conserva en el contenedor y en el tema.

## Aplicación MineCAD

La aplicación se ejecuta directamente en un navegador compatible con WebGL. El código propio, estilos y logo se mantienen separados de la dependencia. La licencia de Three.js no se extiende automáticamente al código de MineCAD o de terceros.
